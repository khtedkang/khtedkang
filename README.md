## How I work

**Question → Evidence → Decision → Execution**

1. Define the real user, decision, and boundary.
2. Organize the evidence and make uncertainty visible.
3. Frame options, roles, risks, dependencies, and stop conditions.
4. Turn the decision into a pilot, partner plan, tool, publication, or repeatable workflow—and test it.
